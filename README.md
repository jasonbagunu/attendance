# 📌 Attendance System Using Barcode Scanner

## 📖 Description
This is a web-based attendance system that uses a **barcode scanner** to record student attendance efficiently and accurately.  
The system automatically logs time-in and time-out when a student ID barcode is scanned.

---

## 🚀 Features
- Barcode-based student attendance scanning
- Automatic time-in and time-out recording
- Student ID recognition
- Attendance record storage
- Date filtering of attendance logs

---

## 🛠 Technologies Used
- PHP
